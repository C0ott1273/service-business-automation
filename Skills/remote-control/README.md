# remote-control

Interactive Telegram inline keyboard control panel for one-tap access to all business operations.

## Usage

Send `/remote` in Telegram to open the control panel. Tap any button to execute that action instantly.

## Categories

- **Schedule & Jobs** — Today's schedule, jobs list
- **Leads & Customers** — Check leads, missed calls
- **Marketing & Growth** — Ads, content, GBP, outreach, competitors, referrals
- **Operations** — Drip stats, bookings, goals, prayer
- **System & Reports** — Pipeline, status, briefing, summary, weather, Bible

## Inputs
- None (activated via /remote command or callback buttons)

## Outputs
- Inline keyboard menus with clickable action buttons
- Each button triggers the corresponding skill and replies with results
